개요

연결된 AI

끊으면 시사가 그 AI를 더 쓰지 않아요. 지금 쓰던 AI면 「AI 없이 쓰기」로 바뀌어요. 바로 적용돼요.

Claude Code 세부 모델

일마다 쓸 Claude 모델이에요. 바꾸면 바로 적용돼요.

캐릭터

고른 캐릭터가 화면에 나오고, 말투와 정해진 말도 그 캐릭터대로 바뀌어요. 아래 「문구」에서 고친 문구는 그대로 써요.

「＋ 새 캐릭터」로 이름·그림·말투를 직접 정해요. 카드의 ✎ 를 누르면 대사를 전부 고칠 수 있어요.

문구

캐릭터가 정해진 때 하는 말이에요. 여러 줄이면 그중 하나를 골라요. {title} 같은 자리표시는 그 문구에 적힌 것만 쓸 수 있어요. 비우면 기본값 — 저장하면 바로 적용돼요.

Slack 채널·DM

끄면 그 대화는 받지도 않고 할 일·브리핑·캐릭터 알림·지시사항·지식그래프에도 안 써요. 채널을 끄면 거기서 나를 @멘션한 글도 같이 빠져요. 다시 켜면 모아 둔 글이 돌아와요.

오늘 할 일 알림

오늘 할 일을 적어 달라거나, 남은 게 있다고 캐릭터가 알려 줘요. AI 연결 없이도 정해진 말로 알려요.

일정 알림

캘린더를 연결하면 일정 몇 분 전에 캐릭터가 춤추며 알려 줘요. 여러 개 고르면 그때마다 한 번씩 알려요.

중요 일정

이 Mac 캘린더 중 이름에 「중요」가 든 캘린더의 일정을 개요·할 일 맨 위에 D-day 로 모아 보여 줘요.

연결 상태

안 되는 게 있으면 [연결 안내], 꺼져 있으면 [연결하기]를 눌러 연결 도우미 화면(메일·이슈는 안내 문서)에서 차근차근 연결해요. 비밀번호·토큰은 여기서 받지 않아요. [연결 해제]는 시사 설정에서 그 연결과 저장된 토큰·주소를 지워요. Claude Code에 등록한 MCP 서버(claude mcp add)는 그대로 남아요.

~/.ssh/config 의 서버예요. 「GPU·작업 보기」를 켜면 2분마다 tmux 와 usagi-run 결과를 확인하고 GPU·폴더를 물어볼 수 있어요. 「작업 기록 받기」는 서버의 Claude Code·Codex 기록을 10분마다 받아요(작업 기록 읽기가 켜져 있어야 해요). 여럿이 쓰는 공용 계정이면 「내 폴더」(예: ~/reo)를 적어요. 그 아래의 tmux·결과·기록만 내 것으로 봐요.

브리핑에 넣을 출처

끈 출처는 정기 브리핑에서 확인하지도, 말하지도 않아요.

이 맥에서 읽는 것

켠 것과 고른 폴더만 읽어요. 처음 설치하면 모두 꺼져 있어요.

연구 노트 그래프(Tine)

고른 그래프의 그날 일지에 「오늘 한 일」을 써요. 그래프 폴더(logseq/config.edn 이 있는 곳)여야 해요.

채팅이 써도 되는 MCP 서버

Claude Code 에 등록한 MCP 서버예요. 켠 서버만 채팅에서 써요. 메일·일정 등 연결한 서비스의 서버는 따로 쓰여요.

자동 머지

여기 있는 레포는 ✓ 없이 머지까지 해요 — 채팅에서 시킨 머지, 시사가 고친 코드로 올린 PR 이 검사(실패·대기 중 검사·충돌·초안)를 통과하면 바로 머지해요. 채팅에서 「이 레포는 알아서 머지까지 해」·「X는 이제 머지 묻고 해」로도 바꿀 수 있어요.

코드 고치기·머지는 Claude Code·Codex·Antigravity 중 하나가 있어야 해요. 연결 도우미에서 연결하면 여기서 고를 수 있어요.

행동 지침

내가 정한 말투·답 모양·일하는 법이에요. 켜 둔 지침은 대화·브리핑·코드 작업 프롬프트에 늘 붙어요(범위대로). 부딪치면 아래쪽(최근) 것이 이겨요. 나에 대해 배운 사실(프로필·지식그래프)과는 따로예요.

나

이름과 다른 이름(쉼표로 나눠요)은 대화·지식그래프에서 나를 알아보는 데 써요. 커밋 작성자는 내 커밋을 알아보고 자동 수정 커밋에 붙어요. 비워 두면 이 맥의 git 설정을 써요.
